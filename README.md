# 🎓 AI Learning Buddy

An AI-powered educational assistant built with **Python, Streamlit, and Google Gemini API** to help students learn concepts interactively through explanations, examples, quizzes, and question answering.

## ✨ Features

* 📖 **Concept Explanations** – Get easy-to-understand explanations of academic topics.
* 🌍 **Real-World Examples** – Understand concepts through practical examples.
* ❓ **Quiz Generation** – Generate questions to test your understanding.
* 💬 **Question Answering** – Ask academic questions and receive AI-generated responses.
* ⚡ **Interactive Interface** – Simple web interface built with Streamlit.
* 🤖 **AI-Powered Learning** – Uses Google Gemini API to generate educational responses.

## 🛠️ Tech Stack

| Technology        | Purpose                 |
| ----------------- | ----------------------- |
| Python            | Application development |
| Streamlit         | Web interface           |
| Google Gemini API | AI-powered responses    |

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/tejasrimalloju05-lab/AI-Learning-Buddy.git
cd AI-Learning-Buddy
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure the Gemini API

Set up your Google Gemini API key according to the configuration used in `app.py`.

**Never upload your API key or other secret credentials to GitHub.**

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
