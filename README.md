# 🎓 AI Learning Buddy

An AI-powered educational assistant built with **Python**, **Streamlit**, and **Google Gemini AI** to help students learn concepts interactively through explanations, quizzes, examples, and question answering.

---

## 📌 Features

- 📖 Explains concepts in simple language
- 🌍 Provides real-world examples
- ❓ Generates quizzes for practice
- 💬 Answers academic questions
- ⚡ Fast and interactive Streamlit interface
- 🤖 Powered by Google Gemini AI

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
